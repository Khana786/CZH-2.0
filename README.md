## About CZH
CZH is a premium, offline-first cybersecurity learning and utility environment designed for Termux. It features a full-screen, hacker-style Hifi terminal interface focused on White Hat security, ethical hacking practice, and defensive tools.

## Key Features
- **CZH HUB (Mission Control):** The central dashboard to access all modules.
- **CZH BLACKSITE (Academy):** 10 offline training modules with lessons, quizzes, and local progress tracking.
- **CZH DARK LAB:** A password-protected, hidden testing environment with OSINT tools, network recon, and Metasploit (via Proot). Only accessible by the Admin.
- **CZH BUG FINDER:** A complete Bug Bounty platform where members submit reports, and Admins can review, accept/reject, and award points (Leaderboard).
- **CZH ADMIN CENTER:** A secure, locked panel for the Founder to monitor system logs, manage members, view Bug Bounty stats, and plan the roadmap.
- **Ethical Cyber Toolkit:** DNS, TLS, Security Headers, WHOIS, Network Health, etc.
- **System Monitor:** Live system diagnostics and hacking-style telemetry.
- **Advanced Integrity Checker:** 12-feature SHA-256 and file integrity auditing.
