# CZH Ethical Cybersecurity Labs

Use these exercises only on systems you own or have explicit permission to test.

## Lab 1: DNS basics
Run `czh-tools`, select DNS lookup, and examine a domain you are authorized to investigate.
Learn: hostnames, DNS resolution, IPv4 and IPv6.

## Lab 2: HTTPS certificates
Select HTTPS certificate information for an authorized website.
Learn: TLS versions, certificate issuer and expiration.

## Lab 3: HTTP security headers
Select HTTPS security headers for a site you own or are allowed to assess.
Learn: HSTS, Content-Security-Policy and related browser protections.
A missing header by itself does not prove a vulnerability.

## Lab 4: File integrity
Select File SHA-256 hash and compare the output with a trusted published checksum.
Learn: integrity verification and why matching hashes matter.

## Safety
Do not use these exercises to access accounts, devices or networks without permission.
This starter toolkit does not perform exploitation, password attacks, or network scanning.
